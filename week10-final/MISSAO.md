## 🎯 Sua Missão

Criar um **projeto original** que demonstre tudo o que você aprendeu no CS50.

### Regras do CS50:

1. O projeto deve ser **mais complexo** que qualquer exercício das semanas anteriores
2. Deve usar **pelo menos 2 tecnologias** diferentes (ex: Python + SQL, Flask + JavaScript, C + arquivos)
3. Deve resolver um **problema real** (nem que seja seu próprio)
4. Deve incluir uma **documentação** explicando o que é e como usar
